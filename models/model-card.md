# Паспорт модели: прогноз массы рыбы (FishGrow)

## Общие сведения

| Поле               | Значение                                                                   |
| ------------------ | -------------------------------------------------------------------------- |
| Файл               | `models/model.joblib` (цепочка `sklearn`: предобработка + модель)          |
| Эксперимент        | E1c — базовое решение автора, воспроизведённое в единой цепочке            |
| Тип модели         | линейная регрессия по логарифмам признаков с логарифмом целевой переменной |
| Задача             | регрессия: масса рыбы в граммах                                            |
| Автор              | `Осипов Владислав Алексееивч`                                              |
| Версия             | v0.1 (после приёмки) · коммит `<git rev-parse --short HEAD>`               |
| Окружение          | Python `3.12.9`, scikit-learn `1.9.1`.                                     |
| Метаданные запуска | `models/model_meta.json`, запись в MLflow (эксперимент `fish-weight`)      |

## Назначение

Учебный прототип: оценка массы рыбы по измерениям. Модель предназначена для демонстрации воспроизводимого рабочего процесса, а не для реального коммерческого взвешивания.

**Не предназначена** для видов, не представленных в обучении, для рыб вне диапазона размеров из таблицы ниже, а также для решений, где ошибка в сотни граммов недопустима.

## Вход и выход

**Вход** (таблица `pandas.DataFrame`, по одной строке на рыбу):

| Поле      | Тип       | Единицы | Обучающий диапазон                                  |
| --------- | --------- | ------- | --------------------------------------------------- |
| `Species` | категория | —       | Bream, Parkki, Perch, Pike, Roach, Smelt, Whitefish |
| `Length3` | число     | см      | 8.8 – 64.0                                          |
| `Height`  | число     | см      | 1.97 – 18.96                                        |
| `Width`   | число     | см      | 1.15 – 8.14                                         |

Дополнительные столбцы во входной таблице игнорируются. Значения `Length3`, `Height`, `Width` должны быть положительными (внутри цепочки берётся логарифм).

**Выход:** массив прогнозов массы в граммах (всегда положительные числа).

**Обработка пропусков:** числовые — медиана обучающей выборки, категориальные — самое частое значение.
**Неизвестный вид:** кодируется нулевым вектором (`handle_unknown="ignore"`), прогноз строится только по размерам, без поправки на вид; точность такого прогноза не оценивалась.

Пример использования:

```python
import joblib
import pandas as pd

model = joblib.load("models/model.joblib")
fish = pd.DataFrame([{"Species": "Perch", "Length3": 30.0, "Height": 8.0, "Width": 4.5}])
print(model.predict(fish))   # масса в граммах
```

## Обучающие данные

- Источник: `data/fish_participant.csv` (учебный набор измерений рыбы с рынка), 111 строк; для обучения использованы 88 строк.
- Разбиение: 80/20, стратификация по `Species`, `random_state = 42`; индексы в `configs/split_indices.json`, контрольная сумма данных SHA-256 в том же файле и в `models/model_meta.json`.
- Тестовая выборка (23 строки) не участвовала ни в обучении, ни в выборе модели и гиперпараметров.
- Файл `fish_holdout_demo.csv` не использовался для оценки: он целиком входит в обучающий файл.
- Строка 13 (Pike, 1550 г) оставлена как допустимое наблюдение.
- Персональных данных нет.

## Предобработка и модель

1. Заполнение пропусков (медиана / самое частое).
2. Натуральный логарифм `Length3`, `Height`, `Width`, затем стандартизация.
3. One-hot кодирование `Species`.
4. Линейная регрессия по логарифму массы; прогноз возвращается обратным преобразованием (экспонента).

Гиперпараметров нет. Генератор случайных чисел в этой модели не используется (seed 42 — в разбиении).

## Качество

| Выборка                                  | MSE            | MAE, г | R²     |
| ---------------------------------------- | -------------- | ------ | ------ |
| Кросс-валидация на обучающей части (5×3) | 3 330 (±1 982) | 32.5   | 0.970  |
| Тест (23 строки), единственное обращение | 1 574          | 25.0   | 0.985  |
| Наивный прогноз средним, тест            | 106 323        | 268.5  | −0.021 |

Ошибка растёт с размером рыбы (MAE по терцилям массы: малые 7 г, средние 27 г, крупные 63 г), но в процентах от массы остаётся примерно постоянной (6–10%). Наибольшая абсолютная ошибка у Bream и Pike. Подробный анализ: `reports/lab02-report.md`, таблицы: `reports/tables/`.

## Ограничения и риски

- Малая выборка: 23 тестовые строки, редкие виды представлены 1–3 строками в тесте; оценки шумные.
- Нет данных о ферме, партии, времени измерения; если зависимые строки попали и в обучение, и в тест, качество завышено.
- Возможна ошибка в данных (например, строка 68, Bream: масса вдвое меньше, чем у рыб почти тех же размеров).
- Самая тяжёлая рыба недооценивается (строка 13: примерно на 200 г).
- Модель не использует упитанность, пол, сезон и другие факторы, влияющие на массу.
- Вывод о причинах не следует делать по коэффициентам модели: связь признаков с массой не доказывает причинности.

## Мониторинг после внедрения (признаки сдвига распределения)

- Входные значения выходят за обучающий диапазон (см. таблицу входа) или меняется соотношение размеров (`Height` / `Length3`, `Width` / `Length3`).
- Появляются виды, которых не было в обучении, или резко меняется доля видов.
- Растёт доля пропусков или появляются нулевые и отрицательные размеры.
- Систематический знак остатков (модель стабильно занижает или завышает) на новых контрольных взвешиваниях.
- При появлении любого из признаков — переоценить модель на свежих размеченных данных и при необходимости переобучить.
